Конфиденциальность

Обновлено: 12 октября 2026 года

В приложении

Настройки, секреты подключений, состояние таймера, история событий и резервные копии хранятся локально в папке data. Учётной записи для оплаты, сбора email для покупки и сервиса активации устройства больше нет. Защищай эту папку и не публикуй её.

Подключённые Twitch, YouTube/Google и донат-сервисы обмениваются с приложением событиями и данными авторизации по своим правилам. GitHub получает запросы обновления и скачивания; Банк России — запросы курсов по нажатию кнопки. Бесплатная версия не отправляет старые данные подписки прежнему платёжному сервису.

На этом сайте

Сайт размещён на GitHub Pages. GitHub может обрабатывать техническую информацию о запросах согласно своей политике. Выбранный язык сохраняется в локальном хранилище браузера. Рекламные и аналитические скрипты сейчас не подключены. Перед будущим подключением рекламы информация будет обновлена и при необходимости добавлено управление согласием.
