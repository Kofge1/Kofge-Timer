# Kofge-Timer website

Public website for Kofge-Timer, a free local Windows timer for OBS, Twitch and donations.

All timer features are available without payment, registration, license keys or device activation.

- Website: https://kofge1.github.io/Kofge-Timer/
- Signed releases: https://github.com/Kofge1/Kofge-Timer/releases
- Download the complete Kofge-Timer-Offline.zip, extract all files, then open Kofge-Timer.exe.
- Keep your data folder when updating. Older paid/test builds require one manual migration to the free edition.
- Support and advertising inquiries: kofge.dev@gmail.com.

Advertising is planned for the website only. No advertising or analytics scripts are connected at present; the app and OBS overlay are ad-free.

The main branch contains only public website files; application archives are distributed as release assets. Never add personal settings, the data folder, credentials, signing keys, payment databases or private configuration to this repository.
