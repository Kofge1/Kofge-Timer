ПЛАТФОРМЫ И ИНТЕГРАЦИИ · v0.1.34

Twitch, YouTube и донаты — в одном таймере

Выбирай Twitch или YouTube как активную платформу стрима. При необходимости отдельно подключай сервис донатов. Поддерживаемые события добавляют время по твоим правилам.

Twitch

Поддерживается

Подписки, подарочные подписки, поддерживаемые продления и до пяти выбранных наград за баллы канала.

YouTube

Новое в v0.1.34

Super Chat, Super Stickers, новые платные членства и пакеты подарочных членств. Для членств можно задать отдельные правила.

Для подключения нужен собственный Google OAuth-клиент. Проверка событий — не чаще раза в 30 секунд, не мгновенно. Проверка на реальном монетизированном эфире ещё не завершена.

Донаты

Поддерживается

DonationAlerts, Streamlabs и StreamElements. Выбирай нужный источник донатов и настраивай начисление времени и конвертацию валют.

OBS Studio

Локальный оверлей

Добавь таймер как «Источник браузера» в OBS или используй компактную панель управления. Live Mode удобен для длинных трансляций.

Важно: Twitch и YouTube нельзя использовать одновременно как две активные платформы. Внешние донаты настраиваются отдельно. Пропущенные во время отключения события YouTube автоматически не восстанавливаются.

ЧЕТЫРЕ ПРОСТЫХ ШАГА

Скачай. Настрой. Выходи в эфир.

01Распакуй весь ZIP

Сохрани все файлы в одной доступной для записи папке. Не запускай EXE прямо из архива.

02Запусти Kofge-Timer.exe

Windows запросит разрешение администратора, затем в браузере откроется локальная панель.

03Выбери подключения

Подключи нужные сервисы и настрой начисления. Вручную таймер работает и без подключений.

04Добавь источник в OBS

Один раз скопируй URL оверлея из панели. Для отображения в OBS приложение должно работать.

Обновляешь старую платную/тестовую сборку? Полностью закрой её, сохрани копию папки data и замени файлы приложения файлами из ZIP. Папку data сохрани. Первый переход выполняется вручную.

Перед запуском

Какие сервисы поддерживаются?

Twitch, YouTube, DonationAlerts, Streamlabs, StreamElements и OBS. Подробности о событиях и ограничениях YouTube — в разделе «Сервисы».

Как подключить YouTube?

Нужен проект Google Cloud с YouTube Data API v3, веб-клиент OAuth и адрес перенаправления, указанный в Kofge-Timer. Введи Client ID и Client Secret в локальном приложении и подключи канал. Пошаговая инструкция находится в README на GitHub.

Открыть настройку YouTube →

Twitch и YouTube могут начислять время одновременно?

Нет. Активной может быть только одна стриминговая платформа. Переключение сохраняет настройки другой платформы и накопленное время таймера. Внешние сервисы донатов подключаются независимо.

Какой архив скачивать?

Для Windows 10/11 x64 выбирай Kofge-Timer-Offline.zip: в нём уже есть необходимая среда выполнения. Перед запуском Kofge-Timer.exe распакуй весь архив. Архив GitHub «Source code» не является готовой программой.

Это действительно бесплатно?

Да. Все функции таймера доступны без ключа, регистрации, платной подписки и ограничения активаций по ПК. Подписки Twitch — события зрителей, а не оплата приложения.

Нужен ли интернет?

Ручное управление и локальный оверлей OBS работают без интернета. События подключённых сервисов требуют сети. Обновления проверяются при запуске, а курсы валют загружаются только по нажатию кнопки.

Как работают обновления?

Приложение проверяет публичные GitHub Releases. Перед установкой проверяются цифровая подпись, размер и SHA-256 архива. Установка запрашивает подтверждение, ставит таймер на паузу и создаёт резервную копию.
